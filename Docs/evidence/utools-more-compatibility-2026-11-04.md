# 更多 uTools 商店插件兼容性实测

2026-11-04。基线为 `main` 的 `946a8cd`，宿主版本 0.1.0，Windows x64、Node 26.13.0、Electron 45.1.0。选择 14 个官方公开目录条目，覆盖 JSON、编码、二维码、颜色、正则、时间戳、计算、密码、文本对比及笔记。样本按功能选择，不能据此推算整个商店的兼容率。

结果：**4 个样本的核心路径可用，其中 2 个还有明确局部问题；3 个运行阶段失败；7 个安装阶段失败。**

2026-11-05 更新：下表保留初测结果。7 个 UPXS 安装失败已由后续格式修复解除，本地安装、商店来源绑定与宿主重启恢复均通过；不据此新增运行功能通过结论，见 [UPXS 格式修复记录](utools-upxs-layout-2026-11-05.md)。

## 问题定位与建议顺序

1. **优先补齐 UPXS 元数据变体。** 7 个失败样本的元数据均能通过现有 XChaCha20-Poly1305 解密，实际字段只有 `key`、`iv`、`timestamp`，没有 `serverDecrypt` 标记。当前 `utools-package.ts` 同时强制要求 `pluginId` 和 `encrypt2`，因此在提取正文之前拒绝。这些结果不能归因为账号或平台授权不可用。后续适配仍应校验目录身份与实际清单，并保留现有路径、体积、完整性和安装事务边界。
2. **处理 API 能力探测和可选功能的错误隔离。** `utools-preload.cts` 对所有未知字符串属性都返回一个抛错函数，也把普通对象的 `valueOf` 当成缺失 API。真实样本说明，这种行为会参与初始化并造成空白页。`registerTool` 和 `getNativeId` 是本轮已观察到的初始化阻塞点，需按真实能力适配，不能仅为让页面启动而伪造授权或成功结果。
3. **修复普通入口与内容输入的兼容细节。** JSONTools 的有效 JSON 输入与格式化正常，普通关键词入口却把 `json` 放入编辑区并产生解析错误。应进一步核对 uTools 的入口 payload 合同，再确定宿主或插件侧的责任；本轮不把它扩大为 JSON 功能全部不可用。
4. **补齐屏幕取色。** 颜色助手的本地转换及数据库设置工作正常，取色按钮才触发 `screenColorPick` 缺失。该样本应标为部分可用。

相关代码：`apps/desktop/electron/plugins/utools-package.ts:74`、`apps/desktop/electron/plugins/utools-preload.cts:159`。本轮只完成诊断和验证记录，没有修改生产兼容逻辑。

## 验证方式与证据

官方索引和详情由生产 `UToolsCatalog` 解析，真实离线包由生产 `stageUToolsPluginPackage` 校验。通过提取的样本再交给生产 `DesktopPluginHost`、管理器和真实兼容子进程，运行原始页面和 preload。安装授权及停止确认由隔离驱动明确选择；本轮没有复测安装预览的人工点击流程。测试没有替换缺失的 uTools API，也没有改写原插件业务代码。

Playwright 操作原输入框、按钮和设置，并读取原页面的结果；JSON 格式化后解析对象核对内容，文本对比核对实际差异行标记。关闭重开使用生产停用／启用路径，更换兼容进程。各插件数据与测试的系统输出目录位于独立测试根目录，未操作用户文档。

证据根目录：`local-build/utools-more-compatibility-20261104/`。

- `staging-report.json`：14 个条目的目录 ID、真实下载 URL、目录版本、提取结果；通过的样本另含实际安装来源 SRI、清单、API 扫描和警告。
- `blocked-package-metadata.json`：7 个拒绝样本的元数据字段和类型；没有记录解密密钥。
- `smoke-report.json`：7 个已安装样本的真实激活结果、页面文本、输入控件和错误。
- `functional-report.json`：原界面操作、已知输入输出、新激活和进程重开结果。
- `runs/`：逐次运行的标准输出、错误日志、原页面 HTML 和截图；颜色、时间戳、文本对比、JSONTools 的功能运行目录分别以 `colorHelper-functional-73f21052`、`ae3ee9f3-functional-a761fb29`、`zaj3ltwy-functional-22706f84`、`zbv8vo3r-functional-c230d62e` 开头。
- `process-cleanup.json`：测试结束后，匹配该测试根目录的 Electron 进程为 0。

脚本为 `local-build/utools-broad-{stage,main,harness,smoke,functional}.*`、`utools-blocked-headers.mjs`。阶段输出为 `local-build/utools-broad-{stage,smoke,functional}.log` 和 `utools-blocked-headers.log`。颜色转换和设置持久化通过同一隔离 harness 实际操作，记录已写入功能报告。

## 边界

本轮覆盖上述具体功能，不代表所有页面、导出格式、网络服务、AI、账号、物理快捷键和多屏 DPI 均可用。没有测试这些样本固定到桌面后的完整组合，也没有对每个样本做 NSIS 安装验收。部分隔离运行有 Chromium GPU 磁盘缓存拒绝访问日志，未把业务结果等同于图形日志无错误。生产代码未变，因此未重复全量单元和浏览器回归；本轮的兼容性结论来自这些真实包及真实进程操作。
