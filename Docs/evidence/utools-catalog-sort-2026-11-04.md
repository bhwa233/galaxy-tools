# uTools 官方目录浏览与排序

2026-11-04。按用户确认实施「接入 uTools 目录浏览，并实现名称、评分、评价数和相关度排序」。本轮没有接入 `.upx/.upxs` 包安装、自动兼容判定或商店更新。

## 使用

重启宿主后，进入「设置 → 插件市场 → 发现插件 → uTools」。排序下拉框提供：

- 自动：无搜索词按名称，有搜索词按相关度。
- 名称 A→Z／Z→A：中文使用拼音顺序，名称中的数字采用自然顺序。
- 评分最高：缺少有效评分放末尾，同分按评价人数降序。
- 评价最多：按评价人数降序。

名称和插件 ID 固定同分次序。先过滤、排序整个目录，再按每页 20 条返回；搜索或排序改变回到第一页。手动选择不会被后续搜索覆盖，分别记住 spark233、uTools 和已安装列表的排序偏好。现有内置目录和已安装列表接入名称、搜索相关度排序；配置页导航保持原行为。

uTools 列表展示真实名称、作者、简介、评分和评价人数，提供官方详情入口。没有下载量、更新时间或兼容证据时不构造这些字段，也不显示安装成功或已验证标记。

## 来源和边界

宿主固定请求 `https://www.u-tools.cn/plugins-search-index.json`；渲染器只能提交查询、排序、页码和刷新标志，不能提供任意来源 URL。主界面使用现有管理 IPC，插件工作区不能调用该目录接口。

索引按需读取，6 小时缓存；并发查询共享一次刷新，过期缓存可立即用于搜索、后台刷新后在后续查询使用新内容。刷新失败保留上次成功目录。缓存文件和响应大小有界，详情地址限制在官方插件详情路径，图标地址限制为已知官方资源来源。浏览目录不会激活插件或启动兼容运行器。

前端保留当前请求代次，切换来源和查询后迟到响应不会覆盖新结果。来源、排序和任务页切换不触发重复安装；排序选定后菜单收起，避免遮挡列表操作。
