# 功能优化实施记录（2026-10-30）

范围依据：[功能优化计划](../functional-improvement-plan-2026-10-30.md)。用户已授权实施 R1–R3、恢复能力、OCR 与搜索增强；首次配置指引、剪贴板空间管理和三条完整实机链路验收已排除。

## 实现

- 翻译历史使用串行持久化提交，写入失败不改变已确认的历史，也不提示删除或清空成功；前端丢弃晚到的旧历史响应。新格式保存完整正文，去重使用完整原文及目标语言；旧格式可能截断的记录带提示，新增历史保存失败返回明确状态。
- OCR 识别结果、原图及修订稿共同存放在插件数据域，最近会话可恢复。自动保存与窗口准备结束共用现有协调机制，保存失败保留待保存稿。未修订结果保留 20 份；修订稿由用户显式删除。
- OCR 原生会话序列化已有 TinyOCR 字符框，前端使用实际坐标拖选、跨行扩选与 Ctrl+A；增加缩放、适应窗口和拖动平移。旧记录及被修订的行按行定位，避免把旧字符坐标误用于新文本。
- 便签修改前保存历史版本；右键菜单提供版本预览及恢复。恢复使用内容指纹拒绝覆盖新变更，并保留被替换的当前正文和当前分类；有独立编辑窗口时要求先关闭。历史引用的附件不被未使用图片清理删除，数据迁移包含历史域。
- 定期备份默认关闭，用户选择目录后可开启。复用一致快照服务、保存确认和插件静止流程，支持间隔、保留份数、立即备份、最近成功与错误状态；更换目录时清空旧位置的成功时间，保留原位置备份。运行中保存的设置不被任务结束状态覆盖；授权和归属清单放在导入恢复域之外，清理仅处理该计划创建的备份。
- 搜索增加本次目录、恢复默认范围、最近搜索和常用条件。每次重用都重新查询；查询条件在插件数据域持久化，最近与常用各最多 50 条，清空最近不删除常用。

新增 IPC 均显式声明策略、参数和返回合同。OCR 会话仅限所属插件页面；备份计划仅限宿主管理页面；便签页面未增加宿主管理权限。实现未增加依赖，沿用现有 UI 原语和桥接。
