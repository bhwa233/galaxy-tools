# 常用 uTools 插件扩展回测与运行修复

2026-11-05，宿主 0.1.0，Windows Electron 45.1.0。延续上一轮的 7 个原包，增加 12 个官方目录条目，共 19 个样本。18 个完成安装，图片拼接条目没有可下载离线包。本轮有 12 个插件的下列核心路径通过，2 个仅部分验证，4 个运行能力受阻；不能据此推算整个商店的兼容率。

## 本轮修复

- CommonJS preload 使用 Node 的编译器和相对模块解析，补齐私有的 `process`、`Buffer`、`global` 和即时定时器绑定，保留 `module/exports/__filename/__dirname`。不向普通页面添加这些 Node 全局变量，不修改原插件代码。
- ready/enter/out 按顺序执行。新内容激活先等待旧 out 完成，并给前端一次提交状态的机会；编码小助手只在组件挂载时读取文件的行为现已正确适配。普通唤起保留原页面；桌面和插件栏切换不重新进入功能。
- out 失败或超时阻止新内容进入，不自动终止进程。超时回调迟到后，下次普通唤起重新确认生命周期，避免把已清空的页面误判为仍已进入。
- 移除“任何未知属性都返回函数”的 API 代理。未实现能力真实返回 `undefined`，普通 `valueOf` 等 JavaScript 行为恢复；实际调用未实现方法仍由现有错误诊断显示。
- `getNativeId` 返回持久化的宿主本地安装 UUID，供插件保存设备相关文档；标识损坏时明确失败，不悄悄改名丢失数据命名空间。它不表示 uTools 账号、购买授权或云同步身份。
- 旧列表保留原选择记录，最多处理 10,000 条、显示 1,000 条，并限制投影约 192 KiB。超限显示复用原搜索框的缩小范围提示；搜索结果可覆盖首屏以外的条目。
- 文本处理原包带有基础 UPXS 布局的 `os/app/developer` 信息对象，现已核实支持；未知字段、异常对象、扩展身份缺失及服务端解密要求仍拒绝。
- 完整构建暴露原生搜索脚本把 Windows 反斜杠路径直接传入 CMake，产生 `Invalid character escape '\c'`。仅将这个源目录参数规范化为正斜杠，完整构建随后通过。

## 生命周期与数据保护

隔离真实 Electron 窗口还通过以下场景：固定到桌面；普通唤起保留编辑内容；新文本／文件／图片进入同一功能；out 报错和真实 15 秒超时都阻止新输入、保留未保存编辑器与进程；迟到回调不自动进入新内容；超时后的普通唤起重试；三次桌面／插件栏切换保持 PID、HWND、WebContents、DOM 和文本；移动调整大小、显隐；取消停止；取消固定失败保留持久入口并重试；恢复原窗口及最大化。

桌面层遮罩的传输边界沿用原隔离夹具，兼容运行器、原窗口及原页面均真实运行。这不替代物理拖拽、混合 DPI 和多屏验收。

Markdown 首次驱动在插件两秒自动保存之前停止了进程，文件仍为空；修正验收顺序为等待实际文件内容写入，再关闭重开。几个早期驱动也使用了隐藏菜单／自定义复选框的错误定位方式，最终结论采用原可见控件和完成条件的复核结果，不把驱动超时记作兼容失败。
