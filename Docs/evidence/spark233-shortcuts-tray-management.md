# 快捷键管理与插件托盘菜单

日期：2026-10-28。

## 实现范围

- 设置窗口增加“快捷键管理”和“托盘菜单”两个独立分类，继续复用设置窗口与桌面桥接。
- 快捷键页统一管理启动器、便签窗口显示/隐藏和插件公开命令；支持名称、所属插件、快捷键搜索，插件详情可跳转到对应筛选。
- 复用快捷键录制器，显示冲突操作名称；显式保存，失败保留草稿，离开和关闭沿用保存/放弃/取消确认。
- 宿主继续采用字段 patch。插件绑定按修改键合并并校验原值；宿主快捷键另外校验原始值，拒绝过期草稿覆盖。
- 快捷键注册采用增量提交；新注册失败释放本次新增项，保留原有工作绑定。插件停用释放该命令注册；旧回调执行前重新检查命令可用性。
- 搜索模式操作通过已有工作区交付机制进入启动器搜索范围，兼容冷启动和已打开启动器。
- SDK 增加可选 `spark233.tray` 声明。菜单项只能引用本插件公开命令，支持文字、本地化、分组、顺序和 checkbox。
- 托盘保留宿主启动器、设置、便签找回和保存后退出入口；业务操作从插件声明生成一级子菜单。
- 托盘设置支持菜单项显隐、插件组和组内操作上移/下移；宿主配置持久化偏好。
- 托盘回调执行前重新检查插件版本、命令可用性、用户隐藏偏好和维护状态。插件停用移除菜单，重新启用恢复偏好。
- 勾选和可用状态属于当前插件实例资源域。Web 使用 `tray/update` capability，可信后台和原生运行时使用 `tray-state` 事件；释放后撤销状态，旧实例不能修改新实例状态。
- 七个官方插件补齐菜单声明并递增补丁版本，第三方示例提供声明。已安装插件需在插件管理中显式更新到新的离线包，宿主不自动替换现有安装。

## 验证边界

Node 功能回归覆盖快捷键注册失败回滚、停用释放和恢复、旧回调失效、声明越权拒绝、托盘排序显隐及状态资源域释放。

浏览器用例使用现有桌面 transport fixture 验证设置交互；它不构成真实系统快捷键或物理托盘点击的验收。

本轮验证结果：

- `pnpm typecheck`、`pnpm lint`、`pnpm fmt --check` 通过；lint 仍报告工作区已有警告。
- `pnpm test`：57 个文件、232 项通过。
- `pnpm test:ui`：8 个文件、11 项通过，包括快捷键失败保留草稿、冲突定位、托盘显隐与排序，以及搜索模式交付。
- 隔离 Windows Electron 45 实测：注册真实全局快捷键；停用释放插件绑定并保留启动器绑定；启用恢复；生成原生 Tray、插件子菜单和勾选状态；释放全部自有注册。结果见 `local-build/shortcuts-tray/native-check.json`。
- `pnpm build` 通过，生成桌面前端、Electron 和七个官方插件离线包。期间工作区宿主拆分曾导致临时编译失败；本记录的构建结果来自这些错误修复后的成功重跑。
- 浏览器截图见 `local-build/browser-ui/screenshots/shortcut-management.png` 和 `tray-management.png`。

没有执行安装器或物理按键、托盘点击；原生检查验证的是 Windows API 注册、释放与原生菜单构造。未替换用户正在运行的实例、用户目录或已安装插件。
