# 主题色切换 · 2026-10-30

常规设置在明暗模式下方新增主题色选项：竹绿、蓝、紫、橙、玫红。使用官方 shadcn Base Nova ToggleGroup 与现有设置保存队列，点击即时预览并自动保存，不新增单独保存入口。错误、警告等语义色不随主色变化。

## 接线

- 宿主配置使用可选 `accentColor`，旧配置默认竹绿。写入沿用现有严格配置校验、磁盘原子保存与 `config-changed` 通知。
- `DesktopAppearance` 为启动器、设置和官方独立窗口应用同一主色；本地缓存用于首次绘制，系统明暗变化不会清除主色选择。
- 共享 UI 的 `theme.css` 为五个主色分别提供浅色/深色的主色、悬停色、选中背景与文字配色。
- SDK 主题协议 1.0 增加可选 `accent`。外部插件通过原有初始上下文与 `onTheme` 通知获取，`applyPluginTheme` 应用数据属性；未提供新字段的旧客户端仍使用默认竹绿。
- UI 中声明单色的内置插件图标使用主题变量；原生 PNG/ICO 按同一份共享 CSS 色板生成每色的浅色/深色版本，通过图标声明中的 `themes` 选择。设置变化时刷新窗口图标、Shell 图标资源路径和托盘；系统明暗变化时调整原生图标明度。启动器沿用主应用 AppID，插件保留各自 AppID。

## 验证

类型检查、lint、294 项 Node 测试和 37 项浏览器测试通过。扩展现有设置页浏览器用例，验证第一次保存尚未完成时再次选择颜色，晚到的响应不会覆盖最后选择，最终保存及缓存均为最后的颜色。

真实 `pnpm dev` / Electron 实测：通过设置页点击“紫”，启动器、设置、文件搜索窗口均收到 `purple`；磁盘配置写入成功，深色主色为 `#b49aff`。诊断随后通过同一界面恢复原来的竹绿，并把设置页保持打开。报告为 `local-build/accent-live-report.json`，截图为 `local-build/accent-settings-purple.png`、`local-build/accent-settings-ready.png`。

读取实际 CSS 计算值验证五种主色的浅色/深色配色：主色与按钮文字、页面背景和选中背景的对比度均达到 4.5:1，报告为 `local-build/accent-contrast-report.json`。该检查针对这些颜色组合，不代表全产品所有内容均完成可访问性验收。

本次复用了现有开发实例和用户数据，没有打包或发布。检查日志为 `local-build/accent-*.log`。
