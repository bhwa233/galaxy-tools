## 发现及修复

| 范围                     | 原问题                                                                                    | 当前行为                                                                                                                                              |
| ------------------------ | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| P6.6 默认翻译方向        | 只凭汉字判断中文，日语“日本語を勉強しています”误译英文；后台和工作区各维护一份判断。      | 共享纯 `language.mjs`，假名/韩文优先译简体中文，其余含汉字默认译英文，其他内容译简体中文；显式目标优先，缓存按实际目标隔离。翻译插件版本为 0.1.1。    |
| P2.5/P2.9 原生初始化失败 | 首次握手失败后，自有进程虽已退出，失败 entry 和 Promise 仍被复用，阻塞重试及普通停用。    | 仅清理已确认退出且从未初始化成功的 entry。未确认退出继续跟踪，观察到退出后才可清理；已接受业务后的崩溃仍保留保存边界。                                |
| P2.5/P2.9 退出部分失败   | A 已释放、B 释放失败时，C 留在 prepared，取消退出后仍无法接收命令，A 的启动服务也未恢复。 | 恢复未释放实例的准备状态，重启本次已释放且仍启用的启动服务；B 的未释放资源保留并可重试，恢复失败与原释放错误一起报告。复用 Manager 原有实例恢复逻辑。 |
