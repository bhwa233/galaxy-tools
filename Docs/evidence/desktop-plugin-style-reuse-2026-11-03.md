# 桌面插件栏复用普通桌面样式

2026-11-03，Windows x64 开发环境。按用户确认，插件栏位置继续独立保存，插件内容复用普通桌面的组件、样式与尺寸。

## 最终行为

- 两处共用 `LayerCardContent`。流量使用原 `DeclarativeCard`，便签使用原 `CapsuleHost`，贴图使用原 `ScreenshotCard`。移除插件栏对流量字号、间距、背景和便签摘要的专用覆盖，插件内容继承当前主题。
- 插件栏保留遮罩、顶部工具栏与位置记录。尺寸由实际插件提供，旧记录的宽高不再覆盖插件；大图在目标工作区内等比收纳。宿主忽略移动请求携带的尺寸，防止刷新或旧请求覆盖插件当前尺寸。
- 拖动、置顶、设置、收起工具条在插件外侧，悬停或键盘聚焦时显示。向上展开的流量排行为管理工具条留出空间，避免遮挡。排行使用原插件模板、进程图标和采集状态。
- 插件栏便签的移动和收起只改变插件栏状态，宿主拒绝该会话直接调用便签的桌面拖动／滚动接口。打开便签沿用原编辑器和焦点交接。悬停预览由宿主提供插件栏中的可信位置，保持业务数据和普通桌面位置不变。
