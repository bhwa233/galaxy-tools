# 统一通知、Base UI 与聚心图标 · 2026-10-30

## 实现

- 将启动器图标切换为已选的「聚心」，生成 SVG、PNG、ICO 和托盘深浅主题图标。宿主标题和图标继续使用既有窗口声明机制，插件保留各自身份。
- shadcn 配置切换到 `base-nova`。对话框、确认框、菜单、复选框、分隔线和 Toast 使用 Base UI；共享 UI 包升至 0.3.0，Button、Input 和 Badge 同步迁移。Command 采用官方 Base 集合的 cmdk 与 Base UI Dialog 组合。直接 Radix 依赖和 UI 源码中的 Radix 导入已移除；cmdk 的间接依赖不在此保证范围内。
- Toast 采用 shadcn Base Toast，保留现有 `showToast` 调用入口。通知在当前窗口顶部居中，宽窗口距顶 56px，窄窗口距顶 8px，避免遮住词典查询框。提示悬浮显示，不推动内容，多条向下展开。
- 相同类型和文案的通知合并并重置计时；成功/普通提示显示 2.5 秒，失败/警告显示 5 秒；支持关闭、悬停暂停、键盘操作和减少动态效果偏好，不抢输入焦点。
- 复制、保存便签、截图保存/删除、剪贴板操作、设置保存、插件安装更新等一次性操作使用 Toast，在操作完成后通知。取消文件对话框保持静默。查询/加载错误、任务进度、持久警告和未保存状态保留在原位置。
