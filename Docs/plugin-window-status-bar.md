# 插件窗口统一状态栏与桌面卡片

日期：2026-11-07

状态：方案已与用户确认（含交互优化 P0–P2），尚未实现。实施清单见 [launcher-todo.md](launcher-todo.md) 的「2026-11-07 插件窗口统一状态栏」。

## 1. 目标

桌面卡片要能显示插件的独立窗口。窗口状态（普通、置顶、常驻桌面）统一由每个窗口顶部的宿主状态栏控制。窗口在普通桌面、插件栏和桌面卡片中显示时，使用同一条状态栏、同一个窗口实例和同一份页面状态。

由此取消以下分散入口：

- 设置页「编辑桌面」全局编辑模式（[DesktopWidgetManager.tsx](../apps/desktop/src/features/desktop-layer/DesktopWidgetManager.tsx) 入口与 [LayerEditor.tsx](../apps/desktop/src/features/desktop-layer/LayerEditor.tsx) 草稿流程）。卡片改为直接通过状态栏拖动，从边缘缩放，位置自动保存。
- 插件栏面板上单独定义的图钉语义。插件栏里的图钉改为同一个窗口模式控件。
- 便签窗口自己的置顶和桌面逻辑。便签窗口使用同一个模式控件；便签胶囊作为特殊浮层保留。

## 2. 已确认决定

1. **强制统一**：所有插件独立窗口都显示宿主状态栏，包括已声明 `titleBar: "custom"` 的 Web 插件。插件不再自绘窗口控制。
2. **窗口模式互斥**：`普通窗口` / `置顶` / `常驻桌面` 三选一。模式控件点击后弹出菜单，每项带图标和文字，当前项打勾；按钮图标显示当前模式。不采用点击循环切换。
3. **收藏与模式分离**：星标只用于把窗口收藏为插件栏顶部的快捷入口，不改变窗口模式，放在状态栏更多菜单和顶部添加列表中。
4. **插件栏添加入口**：插件栏顶部新增「添加插件」，列出可打开的插件窗口，支持搜索。单实例窗口已打开时直接复用。从这里首次打开的窗口默认显示在插件栏中，用户切换为「常驻桌面」后，收起插件栏时继续保留。下次呼出插件栏时恢复上次的面板排列。
5. **不复制、不重载**：切换模式、进出插件栏都只改变原窗口的属性和归属，不重新创建页面，也不在窗口之间搬移内容。输入内容、结果、选中项和正在执行的任务都要保留。
6. **常驻桌面卡片点击即临时浮起**：点击卡片时临时浮到最前并获得焦点，失去焦点后退回桌面层。插件栏快捷键（默认 `Ctrl+Alt+D`）可一次调出全部桌面卡片。
7. **常驻桌面时 × 表示移出桌面**：窗口隐藏、页面状态保留，模式恢复为普通窗口。停止插件只放在更多菜单中，并沿用保存确认。
8. **常驻是持久的**：应用重启或开机自启后，常驻桌面的窗口按保存的位置和尺寸自动打开。
9. **临时工作界面不在范围内**：截图取框、贴图、快捷剪贴板、便签胶囊等特殊浮层不加状态栏，继续走各自的流程。

## 3. 三类窗口的现状与接法

| 类别                                                                                                                                                   | 当前创建方式                                                                                                                              | 当前标题栏                                                                                      | 统一接法                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 官方可信工作区（便签、剪贴板、词典翻译、OCR、截图历史；文件搜索窗口将改用 Everything 窗口，见 [everything-file-search.md](everything-file-search.md)） | [desktop-windows.ts](../apps/desktop/electron/host/desktop-windows.ts) 通过 `createHostWindow` 创建无边框窗口，使用宿主 preload           | 页面内的 [WorkspaceTitleBar](../apps/desktop/src/features/windows/WorkspaceTitleBar.tsx)        | 扩展 `WorkspaceTitleBar`，加入模式控件和更多菜单；不改窗口结构             |
| Web 插件（流量、快捷链接、第三方）                                                                                                                     | [web-host.ts](../apps/desktop/electron/plugins/web-host.ts) `open()` 直接用插件页面作为整个窗口，隔离 session，`frame` 由 `titleBar` 决定 | 原生边框，或插件自绘 [window-title-bar.tsx](../packages/ui/src/components/window-title-bar.tsx) | 改为宿主无边框壳窗口：顶部由宿主绘制状态栏，插件页面放入 `WebContentsView` |
| uTools 兼容插件                                                                                                                                        | [utools-runner.cts](../apps/desktop/electron/plugins/utools-runner.cts) 壳窗口加 `WebContentsView`                                        | 宿主壳窗口自绘的 40/48px 顶部栏                                                                 | 顶部栏替换为统一状态栏组件，复用现有桌面接入                               |

官方工作区的页面本身就是宿主可信代码，状态栏可以继续在页面内渲染。Web 插件页面不可信，状态栏必须位于宿主控制的壳窗口中，插件无法绘制、遮挡或伪造这些控件。

## 4. 状态栏

视觉基线沿用 [插件独立窗口布局统一 PRD](plugin-window-layout-prd.md) 第 4 节：常规高度 48px，以便签管理为参考，拖动和双击最大化规则不变。三类窗口共用同一套视觉和状态模型。

| 区域           | 内容                                                                                                  |
| -------------- | ----------------------------------------------------------------------------------------------------- |
| 左侧（可拖动） | 插件图标（叠加运行状态标记）、窗口名称；插件可设置副标题，宿主限制长度并按纯文本渲染                  |
| 中间           | 拖动区。官方工作区按 PRD 保留原有同行业务入口；Web 插件首版不提供宿主栏内业务按钮，业务操作留在内容区 |
| 右侧：窗口模式 | 模式菜单按钮：普通窗口、置顶、常驻桌面                                                                |
| 右侧：更多菜单 | 收藏到插件栏顶部、锁定位置（仅常驻桌面）、重新加载、插件设置、开发者工具、停止插件                    |
| 右侧：窗口控制 | 最小化、最大化/还原、关闭；常驻桌面时只保留 ×（移出桌面）                                             |

**运行状态标记**：插件图标上叠加小标记，分别表示未保存（圆点）、任务进行中（转圈）、出错（红点）。官方工作区由页面状态提供，Web 插件通过宿主接口上报，由宿主渲染。状态栏隐藏时，标记仍保留在卡片角落。

**常驻桌面时的状态栏**：

- 平时隐藏，卡片顶部保留一条细的拖动区。
- 鼠标悬停约 200–300ms 后才显示，避免经过时闪烁；移开后延迟隐藏。
- 卡片获得键盘焦点或打开菜单时，状态栏保持显示。
- 锁定位置后不响应拖动和缩放，也不再悬停显示状态栏；聚焦时仍可显示，用于解锁。

## 5. 窗口模式与生命周期

| 操作                       | 结果                                                                                                                              |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 切换为置顶                 | 原窗口 `alwaysOnTop`，仍是普通应用窗口                                                                                            |
| 切换为常驻桌面             | 原窗口交给桌面层管理，按桌面层的身份、Z 序和故障恢复规则显示（见 [desktop-widget-layer.md](desktop-widget-layer.md)）；不停止插件 |
| 首次切换为常驻桌面         | 播放短暂的下沉过渡，并提示一次「已放到桌面，按 Ctrl+Alt+D 随时呼出」；之后不再提示                                                |
| 点击常驻桌面卡片           | 临时浮到最前并获得焦点；失去焦点后退回桌面层，不改变模式                                                                          |
| 从常驻桌面切回普通窗口     | 原窗口退出桌面层，恢复普通窗口的几何、聚焦和任务栏属性                                                                            |
| 在状态栏拖动或从边缘缩放   | 只调整当前窗口；位置和尺寸按模式（普通、常驻桌面、插件栏）分别记忆，松手后保存                                                    |
| 收起插件栏                 | 非常驻桌面的窗口隐藏，插件进程和页面状态保留                                                                                      |
| 常驻桌面时点击 ×           | 移出桌面：窗口隐藏、页面状态保留，模式恢复为普通窗口，不触发停止流程                                                              |
| 非常驻时点击 ×、或停止插件 | 沿用原有关闭流程：Web 插件走 `prepareStop`，官方工作区走各自的保存和取消确认。保存失败或确认超时不能强制结束业务进程              |
| 应用重启、开机自启         | 常驻桌面的窗口按保存的模式、显示器、位置和尺寸自动打开                                                                            |
| 插件被停用、卸载或启动失败 | 对应卡片从桌面移除；设置页卡片列表显示原因，插件恢复后可一键放回                                                                  |

**尺寸下限**：插件可以为每个窗口声明桌面卡片的最小尺寸，宿主在缩放时强制执行。低于普通窗口尺寸时，内容区应切换为窄布局，不能被挤坏；官方工作区按 PRD 4.4 的窄窗口规则检查。

设置页的桌面卡片列表保留显示、隐藏、恢复故障卡片和移除卡片的功能，不再提供全局调整模式。

## 6. 布局辅助

- **吸附对齐**：拖动卡片时吸附到工作区边缘和其他卡片的边缘，显示对齐参考线；按住 `Alt` 拖动可暂时取消吸附。松手后保存最终位置。
- **多显示器**：卡片按显示器记忆位置和尺寸（以显示器标识和 DIP 坐标保存）。显示器断开时，卡片移到主显示器并保留原记录；同一显示器重新接入时放回原位。DPI 变化和屏幕失效沿用 [desktop-widget-layer.md](desktop-widget-layer.md) 9.2 节的规则。
- **重复打开时定位**：从插件栏或启动器打开一个已经常驻桌面的单实例窗口时，不新建窗口，而是浮起对应卡片并短暂高亮边框，让用户知道它已经在桌面上。

## 7. Web 插件合同变化

- SDK 清单中的 `titleBar`（[packages/sdk/src/manifest.ts](../packages/sdk/src/manifest.ts)）标为废弃：`"custom"` 仍能通过校验以兼容旧包，但不再生效。宿主 API 升一个次版本，并在 [SDK README](../packages/sdk/README.md) 中说明。
- `client.window.minimize/toggleMaximize/isMaximized` 和 `client.close` 保留，改为作用于宿主壳窗口，不再要求声明 `custom`。窗口操作仍由宿主执行和校验，不接受插件传入的目标窗口、坐标或标志位。
- 新增副标题设置接口和运行状态上报接口（未保存、进行中、出错），宿主负责限制长度、按纯文本显示，并只渲染为固定的状态标记。
- 窗口声明新增可选的桌面卡片最小尺寸。
- 原先绑定在插件窗口 `webContents` 上的安全约束需要全部迁到内容视图的 `webContents`：隔离 session、请求过滤、导航与重定向拦截、`setWindowOpenHandler`、崩溃检测、DevTools 快捷键和窗口身份校验。宿主状态栏使用独立的可信 preload，不与插件 preload 共用。
- 流量监控和快捷链接删除自绘的 `WindowTitleBar` 和最大化状态同步，移除 `titleBar: "custom"`，并调整页面顶部间距。流量 HUD（桌面小组件层）不在此次改动范围内。

## 8. 代价与限制

- Web 插件窗口改为无边框后，Windows 上失去原生边框的贴靠布局弹窗，拖到屏幕边缘的贴靠和边缘缩放仍保留。官方工作区、uTools 窗口和流量监控目前已是这种体验。
- 第三方插件如果自绘了标题栏，在新版宿主中会显示两层标题栏，需要插件作者删除自绘部分。
- 常驻桌面卡片点击浮起后会短暂遮挡其他应用；失去焦点即退回，不提供“始终在桌面层输入”的选项。
- macOS 的窗口控制位置沿用 PRD 4.3 的约定，首轮验收以 Windows 为准。

## 9. 实施顺序

1. web-host 改为壳窗口加内容视图，状态栏先只包含窗口控制，确保与现有行为一致。
2. 抽出共用状态栏组件（含模式菜单、更多菜单、运行状态标记），供 `WorkspaceTitleBar`、web-host 壳窗口和 uTools 壳窗口使用。
3. 实现窗口模式状态机并接入桌面层：点击浮起、× 移出桌面、按模式记忆位置和尺寸、重启恢复、停用和卸载时移除；移除设置页「编辑桌面」全局模式，插件栏图钉改为模式控件。
4. 便签窗口改用同一个模式控件，迁移原有置顶和桌面设置。
5. 常驻桌面的状态栏悬停显示、锁定位置、首次切换提示与过渡、卡片最小尺寸。
6. 迁移流量监控和快捷链接，废弃 `titleBar`，增加副标题、运行状态和最小尺寸声明，升级宿主 API 并更新 SDK 文档。
7. 插件栏顶部加入「添加插件」入口和收藏。
8. 布局辅助：吸附对齐、多显示器记忆、重复打开时定位高亮。
9. 最后进行 UI 自动化和视觉验收。

验证遵循 AGENTS.md：每个阶段跑类型、lint 和构建门禁；只为保存确认（× 移出桌面不得触发停止或丢失状态）、权限边界（宿主状态栏不可被插件调用或伪造）、模式切换不重载页面、重启恢复这几项关键不变量补最少的回归测试；冒烟测试数据隔离在 `local-build/`。

## 10. 实施记录（2026-11-07）

W1–W9 已实施，与上文的偏差：

- 常驻桌面卡片的状态栏在失焦时折叠为 6px 细条，悬停约 250ms 展开；网页插件壳窗口由宿主轮询光标位置判断何时折回，因为拖动区不向页面派发鼠标事件。
- 首次切换提示只在用户主动放到桌面时出现，显示约 8 秒，快捷键取自设置；重启恢复不会消耗这次提示。
- 吸附对齐只吸附工作区和其他可见卡片的边缘（12px），没有参考线，也没有按住 `Alt` 取消吸附。
- 「收藏到插件栏」放在插件栏「添加插件」列表里（星标），不在每个窗口的更多菜单中。
- 更多菜单目前包含锁定位置（仅常驻桌面）和重新加载；插件设置、开发者工具、停止插件未加入。
- 便签纸片、胶囊和 uTools 窗口保留各自的桌面呈现，不接入锁定和折叠。
