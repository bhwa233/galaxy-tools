## 首版范围

- 导入包含 `plugin.json` 的预构建目录，复用现有安装预览、显式代码信任、不可变版本、更新备份及卸载事务。
- 原插件文件保留在包内独立目录；宿主管理稳定身份和兼容描述，不要求修改插件源码。
- 按需启动独立 Electron 运行器，主宿主不执行第三方 preload。兼容窗口复用共享标题栏、Input、Button 和主题。
- 支持关键词、文本正则/over、图片、文件匹配。正则放工作线程并设时间预算；文件/图片仅在宿主解析有效资源后传给受信插件。
- 支持生命周期、preload CommonJS/纯 JS 依赖、本地数据库、子输入、主搜索结果推送、动态功能、常用系统 API 和旧列表模板。
- 数据库提供本地同步调用、文档版本/冲突和附件语义，不接 uTools 云同步。同步调用只进入该插件的兼容进程。
- `.upx`、市场更新、账号/支付、云同步、ubrowser、任意原生 `.node`、AI Agent 工具及完整系统窗口匹配不属于首版。

## 关键约束

兼容进程隔离崩溃和同步阻塞，不是 Windows 权限沙箱。第三方 Node 插件仍以当前用户权限运行。安装预览不得执行 preload。旧插件没有 spark233 保存确认协议；更新/停用必须请求明确的关闭确认或使用已验证的保存处理，不能假装任意异步任务都已保存。云 API 不返回虚构成功。

官方当前文档的运行环境为 Electron 34.5.8 / Node 20.19.1，本项目 Electron 45.1.0。纯 JS 优先；原生模块和依赖版本行为的插件逐项判定。
