# 胶囊与贴边队列

## 已确认的交互

本轮以本地 PaperTodo 的胶囊交互为参考，保留花笺的 Markdown 数据与 React 编辑器。

- 纸片原关闭按钮改为折叠，`Ctrl+W` 同样折叠。单张胶囊最右侧的“×”隐藏对应便签，保留正文和置顶偏好，托盘或便签列表可找回；纸片/胶囊右键仍提供“隐藏到托盘”。主胶囊继续负责整队收放。
- 单张胶囊采用约 160 DIP 的紧凑宽度，贴边和悬浮共用。标题从左向右显示，为右侧关闭按钮预留空间；超长省略，悬停可查看完整标题及现有正文预览。
- 磁贴通过右键“切回便签”或右上角编辑按钮回到同一窗口的 便签小窗；保留正文，不依赖可选的双击编辑设置。磁贴右键优先于纸片通用菜单，窗口系统菜单也提供切回入口。
- 首次折叠自动进入当前显示器最近的左/右/顶部边缘。左右仍按列排列，顶部横向排列、首次默认居中；三条边各自保存独立队列。拖离边缘可成为桌面悬浮胶囊，拖近另一边或其他显示器可重新停靠，普通胶囊右键也提供“移到左侧 / 移到右侧 / 移到顶部”。这里的边缘使用显示器可用工作区，避开任务栏。
- 折叠前必须可靠保存。失败时保留编辑器，不能假装折叠成功；成功后销毁正文窗口。
- 胶囊普通情况下置顶；展开后的便签遵循自己的置顶设置。检测到外部全屏窗口时降低对应屏幕的窗口层级并置于该全屏窗口之后，结束后恢复。
- 胶囊悬停展示只读预览，不抢焦点；顶部向下展开，左右向屏幕内侧展开。移动到卡片可以滚动；离开胶囊、卡片及二者间的窄通道后收回。预览跟随该便签保存的 MD/文本模式，展开后使用 MD 预览/文本编辑切换；新便签默认文本模式。
- 单击普通胶囊展开便签，恢复其独立保存的展开位置与尺寸。点击使用独立的激活入口；按下后移动超过阈值才启动拖动，拖动结束或取消不会触发点击。按 PaperTodo 默认规则，展开后保留边缘入口；再次单击用于找回/聚焦，不自动折叠。展开入口仍可在边缘队列间移动；拖为自由悬浮胶囊需要先折叠。
- 每队首个主胶囊控制整队：单击收放入口，沿当前边缘拖动调整队列位置（左右调整高度、顶部调整横向起点），拖向其他边缘或显示器可整队迁移；右键提供托盘同一份全局菜单。
- 主胶囊高 32 DIP、宽度从 84 DIP 起，花形和收放箭头使用固定尺寸矢量图标，数量采用居中的等宽数字列，多位数量按需扩宽。普通胶囊的图标、标题和关闭按钮沿同一垂直中心线排列。
- 单张胶囊可沿队列方向重排。队列过长时用滚轮滚动，顶部支持触控板横向滚动和普通滚轮转横向滚动。溢出胶囊在主胶囊之后裁切，主胶囊始终可操作，透明间隙不阻挡桌面点击。
- 重启恢复展开、隐藏、贴边、悬浮、显示器与边缘、队列顺序、队列收放、起始位置和滚动位置。顶部手动移动后保存横向起点，收起再展开保留滚动位置。

## 实现边界

`electron/main.ts` 中的布局表是每张便签的唯一状态来源。展开矩形 `bounds` 与 `capsule` 位置分开；`folded` 不等于隐藏，`visible=false` 才会退出桌面和队列。布局协议升级到 version 2，兼容不含胶囊字段的 version 1。

`electron/capsules.ts` 只协调桌面呈现与交互；`electron/capsule-layout.ts` 处理队列、排序与屏幕 DIP 几何。每个有内容的屏幕边缘共用一个窗口，全应用共用一个预览窗口，悬浮胶囊单独承载；不为每个收纳便签保留正文 renderer。

`src/features/capsules/` 提供胶囊/主胶囊和预览界面，复用现有主题、字体和 MarkdownPreview。Windows 原生窗口形状只包含实际胶囊，透明空白不拦截桌面鼠标。

拖动使用现有 Pointer Capture 与 Electron 屏幕坐标。主进程拥有起拖成员、目标边缘及最终落点，显示器/DPI 变化时取消当前手势并恢复。整队迁移提交前重新检查成员，避免把已经隐藏或删除的便签一起迁走。

胶囊预加载仍启用 sandbox、contextIsolation，主进程验证来源并限制辅助窗口可调用的命令。辅助窗口不能直接调用便签写入/删除、文件授权或任意窗口控制。

## Windows 适配

`electron/windows.ts` 保留之前的 GPU 工作目录修复，并启动 `FullscreenWatcher.cs` 对应的小型 Windows 观察进程。它使用 Win32 查询前台窗口、显示器和窗口矩形；不安装输入钩子、不激活窗口。只在对应显示器有外部全屏窗口时调整本应用窗口的 Z 序。

首次运行使用 Windows 11 自带 .NET Framework 编译器，将随应用提供的固定源码编译到配置目录的 `native/` 缓存，按源码 SHA-256 命名复用。运行期间不常驻 PowerShell，不需要 Rust、额外 npm 原生模块或单独安装 .NET SDK。若系统策略阻止编译/启动，日志会记录 `fullscreen-watcher` 错误；胶囊功能仍可用，但全屏避让需要修复运行环境。

## 验证

纯函数测试覆盖负坐标屏幕、工作区约束、三边选择、顶部居中与横向锚点、溢出滚动/裁切、预览方向与窄通道、横纵重排、整队迁移与隐藏成员/展开几何保持。

Windows 集成探针复用 `scripts/smoke-windows.ps1`，使用独立数据目录，检查保存失败保留、折叠释放、队列复用、主胶囊收放、辅助窗口权限和预览无焦点。探针通过 Electron 鼠标按下/移动/抬起事件验证主胶囊收放、轻微位移点击、普通和悬浮胶囊展开、拖动丢失捕获后的取消、关闭按钮隐藏；不能替代真实鼠标跨屏拖动、混合 DPI、全屏游戏和输入法的交互验收。

PaperTodo 的插件、脚本胶囊、可编辑待办预览、实验性材质和 DirectComposition 动画不属于本轮迁移。

## 统一便签列表

主窗口、快捷便签、桌面纸片、磁贴和胶囊均引用同一个便签 ID。界面将“笔记”统一称为“便签”，列表右键新增“贴到桌面”；第一次打开沿用快捷便签的现有外观，已有窗口只找回并保留当前编辑/磁贴模式，不创建第二份正文。

列表当前目标有未保存更改时先提交保存；保存失败则停留。桌面 NotePad 订阅原有 `notes-changed` 事件，在自身没有未保存更改、没有待完成保存且异步结果仍对应当前便签时刷新正文。列表侧沿用现有竞态保护。此处不保证两个窗口同时编辑同一正文时自动合并；用户主动提交的写入仍沿用最后保存覆盖的现有语义，冲突提示仍在 TODO 中。

Windows 原生探针新增通过实际列表右键打开目标、重复打开复用窗口/不复制、列表到桌面与桌面到列表的保存同步、保留桌面未保存输入的检查，见 `Docs/evidence/unified-notes-windows-smoke.json`。

## 置顶与桌面状态

- 列表行展示“已置顶”与“已贴桌面 / 胶囊 / 已隐藏 / 未贴桌面”，置顶可从列表行按钮、右键菜单、主编辑工具栏或纸片按钮修改并同步。
- 置顶仅在原分类内排到前面；置顶便签与普通便签各自按最近修改时间排序，不改变分类归属、不创建全局置顶区、不重复显示。
- 列表中置顶未贴桌面的便签只记录偏好，不创建 BrowserWindow。之后贴到桌面自动应用置顶。取消置顶恢复原有日期排序。
- 工具栏图钉现在明确表示置顶；旁边的显示器图标负责“贴到桌面”。原磁贴外观仍可在桌面便签中切换。

`electron-layout.json` 的单张布局记录继续作为唯一状态来源，置顶使用逻辑字段 `topmost`；新增可选字段 `everOpened=false` 表示仅保存偏好、尚未打开过。旧记录缺少该字段时按既有桌面记录恢复。正文和元数据协议保持不变，置顶不修改正文的 `updatedAt`。

列表/纸片通过带递增版本的 `note-window-states-changed` 快照同步，初次读取的旧响应不能覆盖新事件。快照只从布局与实际窗口显隐计算，发布状态不读取或尝试修复正文元数据。胶囊默认置顶和全屏避让产生的临时 OS 层级不会改变用户的便签置顶偏好。
