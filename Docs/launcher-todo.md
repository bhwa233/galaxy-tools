## 2026-11-10 插件显示与卡片桌面重设计

已确认[启动器、插件窗口与卡片桌面方案](plugin-display-and-card-desktop.md)，正在分支 `codex/plugin-window-framework` 实施。插件统一声明命令和窗口，允许无窗口；启动器负责命令与快捷操作，卡片桌面只集中展示声明可添加的业务窗口。普通桌面、卡片桌面是两种显示环境，不提供「固定到桌面」状态或操作。

具体代码改动见[技术方案](plugin-window-framework-tech-design.md)。分期为 T0 风险验证 → T1 SDK 与窗口目录 → T2 存储和协调器 → T3 卡片桌面接入 → T4 官方插件与 uTools → T5 顶部入口及交付验证；当前实现和证据见[进度记录](plugin-window-framework-progress.md)。下方勾选依据为当前实现及对应本地验证；尚需原生或物理交互证明的项目继续保持未勾选。

- [x] 建立公开命令、窗口类型、窗口实例与展示关系的统一管理；窗口可以为零，启动器不自动列出所有窗口，快捷操作不进入卡片桌面。
- [x] 插件按窗口声明入口、名称、图标、可添加性、用途、尺寸、窗口操作、复用能力及恢复参数；卡片桌面按“插件 → 可添加业务窗口”生成目录，不按完整／精简外观分两套体系。
- [x] 卡片桌面建立独立添加清单，便签管理、单条便签、流量详情及网速悬浮窗按声明接入；普通打开先复用目标环境，允许多实例但该环境无匹配窗口时新建；「＋」按能力新增，添加后留在卡片桌面。
- [x] 启动器打开窗口默认普通桌面；插件内部只对声明支持卡片桌面的业务窗口跟随环境，不嵌入未支持窗口。业务窗口保留至用户关闭，设置、确认、文件选择等临时交互不加入长期清单。
- [x] 默认显示完整标题栏，插件开发时按具体窗口声明可隐藏，用户不可覆盖；流量详情和便签管理显示，网速悬浮窗和单条便签隐藏宿主标题栏，保留各自业务界面。
