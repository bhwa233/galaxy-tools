## 发布前验收

- [ ] 真鼠标拖动主窗口与纸片，缩放四角，验证点击按钮不触发拖动。
- [ ] Windows 中文输入法：组合输入、候选窗、复制粘贴、快捷键录制；系统保留组合不保证可捕获。
- [ ] 多显示器与 100/125/150/200% DPI，热拔插后窗口可找回，拖动跨屏正常。
- [ ] 从资源管理器拖入图片/Markdown，检查重复插图、路径授权和原文编辑。
- [ ] 真实托盘点击找回、全局快捷键显示/隐藏、安装版开机启动和文件关联。
- [ ] 安装/升级/卸载：正文与图片保留，身份不覆盖上游 Tauri 安装，恢复备份流程可操作。
- [ ] 远程 Windows CI 实跑检查与 NSIS 构建；配置自己的签名/正式发布流程。
- [ ] 用最终 UI 复测 3、5、20 张展开，以及全部收起、回收后重开、长时间编辑；统计完整进程树 PWS/Private Bytes，不将系统 WebView 或 PID 复用混入结果。
- [ ] 做断电/强杀、磁盘满、占用文件、目录迁移中断的恢复验收，明确多文件提交的限制。
- [ ] 多窗口同时编辑同一正文的冲突提示（当前仍遵循原项目最后写入覆盖的语义）。
