## v0.1.1

### 常用 uTools 插件兼容修复

- 支持已核实的基础 UPXS 元数据及导出信息字段，继续校验扩展身份、商店来源、版本和包完整性。
- 补齐受信 preload 的 CommonJS 环境，修复部分插件因缺少 `process`、`Buffer` 或即时定时器而无法使用的问题。
- 同一功能接收新文件时，等待原退出回调和页面状态更新，再进入新内容；普通唤起及桌面／插件栏切换继续保留编辑状态。
- 退出回调失败或超时后阻止新输入，保留进程，并允许后续重试。
- 提供稳定的本地设备文档标识，修正可选 API 探测，支持有预算的大列表显示和关键词搜索。
- 修复 Windows 原生搜索构建的 CMake 路径转义问题。

### 验证与当前范围

- 19 个目录样本中，18 个可安装，12 个插件的已测核心功能通过，涵盖 JSON、计算器、编码、正则、待办、Markdown、二维码、密码、文本处理与图片转 PDF。
- 已验证代表插件的真实进程重启、保存恢复，以及桌面固定、切换和失败保护。
- 部分插件仍受 uTools 版本检查、`sharp`、`ubrowser` 或外部翻译服务配置限制；安装成功不表示全部功能兼容。
- 详细结果与安装包、物理系统交互的验收边界见[常用插件扩展回测](../evidence/utools-common-plugins-2026-11-05.md)。
