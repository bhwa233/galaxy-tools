## v0.1.0

### uTools 商店与桌面插件

- 插件市场接入 uTools 官方公开目录，支持名称、评分、评价人数和搜索相关度排序。
- 支持导入本地 `.upx/.upxs`，以及在目录中「下载并检查」后通过现有安装确认流程安装。
- 支持确认绑定商店更新来源、检查新版本和更新安装；相同版本内容变化需要单独确认。
- 与已安装代码完全一致时，只更新来源记录，保留原进程、页面及编辑状态。
- uTools 插件可以固定到桌面，复用当前兼容进程、窗口和原页面；支持移动、调整大小、显隐及插件栏切换，桌面与插件栏分别记忆位置。
- 桌面外框和操作栏复用普通桌面插件样式。

### 修复与安装保护

- 固定后重新打开同一功能的新文本、文件或图片，正确传入新内容；单纯唤起继续保留编辑状态。
- 取消固定时先确认恢复普通窗口，失败则保留布局和可重试管理入口。
- 商店安装校验实际包身份、版本、来源与完整性，更新继续复用现有代码信任、保存确认、备份及事务流程。
- 取消或无法完成保存确认时，保留正在运行的插件和原数据。

### 当前范围

- 仅支持已核实的离线包格式；安装成功不等于所有插件功能均已兼容。
- 不接入 uTools 账号、付费授权和云同步；程序重启后尚不恢复上次传入的文件或图片上下文。
- 真实 UPX 导入、官方 UPXS 升级、升级取消、已保存数据保留及来源持久化已验证。验证边界见[商店安装与更新记录](../evidence/utools-store-install-update-2026-11-04.md)。
