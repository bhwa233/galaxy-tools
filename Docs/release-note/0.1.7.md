## v0.1.7

### 插件独立发布

- 快捷链接、流量监控、应用搜索、文件搜索、翻译、OCR、截图改为各自独立发布到 npm（`@spark233/plugin-*`），带来源证明；插件有新版本时，会在插件设置里单独提示更新，不必等宿主发版。
- 安装包内置的插件直接使用 npm 上已发布的同一个包。
- 便签和剪贴板仍随安装包一起发布。

### 文件搜索

- 搜索逻辑移入文件搜索插件自己的后台进程（插件 0.3.0）。打开、定位和复制路径仍由宿主执行，并会再次确认路径不在宿主的私有数据目录里。
- 已安装的旧版文件搜索插件会在启动时自动替换为新版本。

### 插件版本

- 文件搜索 0.3.0、翻译 0.1.10、OCR 0.1.3、截图 0.1.6、快捷链接 0.1.3、流量监控 0.2.7、应用搜索 1.1.8、便签 0.1.6、剪贴板 0.1.5。

### 验证

- typecheck、lint 通过；单元测试 342 项通过；真实 Everything 的隔离冒烟测试通过；七个独立插件的发布指纹连续两次构建一致。
