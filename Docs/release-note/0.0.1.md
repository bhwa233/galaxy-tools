## v0.0.1

### 首个公开版本：启动器 + 七个官方插件

spark233 0.0.1 是第一个对外发布的版本：Windows 11 x64 桌面启动器，采用 Electron 45 + React 19 + shadcn 竹绿色主题，内置七个官方插件并默认启用。

#### 启动器

- 关键词、别名、拼音（全拼与首字母）、文本规则与模式切换（应用 / 文件 / 内容 / 词典 / 便签等）。
- 首次引导、托盘驻留、全局快捷键唤出，失焦自动隐藏。
- 原生划词：在其它应用中选中文本后唤出启动器，选中内容自动填入输入框。
- 启动器内 Ctrl+V 可粘贴资源管理器中复制的文件，效果与拖入一致。

#### 官方插件

- **便签**：Markdown 编辑器、分栏预览、磁贴模式、提醒与备份恢复。
- **截图**：ScreenCapture 原生框选、标注与历史。
- **OCR**：ImageReader 取字，支持整图与部分选字。
- **翻译**：ECDICT 本地词典 + 可选 OpenAI 兼容 AI 翻译。
- **剪贴板**：历史记录与回填。
- **应用搜索**：开始菜单应用、快捷方式与自定义入口，拼音匹配。
- **文件搜索**：Pulse 原生 MFT/USN 索引与正文检索。

#### 应用内更新

- 主程序通过 GitHub Releases 检查、下载并安装更新，安装前先让所有窗口完成保存，保存失败会取消本次更新。
- 支持自动检查（默认开启）与自动下载（默认关闭），可在设置中选择稳定版 / 测试版通道。
- 本版本不签名：安装时 Windows SmartScreen 可能提示未知发布者，请核对下载来源为 [Releases](https://github.com/bhwa233/galaxy-tools/releases)。完整性由发布清单中的 SHA-512 校验保证。

#### 已知限制

- 仅支持 Windows x64；版本号采用 0.0.1 起的新序列，不覆盖此前的 1.x 内部构建，升级需卸载重装。
- 不支持降级、不支持自动回滚，不接入 Mirror酱等第三方下载源。
- 一键安装为静默安装，不会注册 Windows 搜索服务；可在应用内的搜索设置中提权安装。
- 由 1.3.0 内部构建创建的备份会被视为“较新版本创建”而拒绝恢复（fail-closed，不会丢数据）。
