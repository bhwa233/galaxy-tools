## v0.1.6

### 插件窗口状态栏与窗口模式

- 所有插件窗口（网页插件、官方工作区、便签管理、uTools 窗口）使用统一的宿主状态栏：标题、副标题、运行状态、窗口模式菜单、更多菜单和窗口控制。
- 窗口模式分为普通窗口、置顶和常驻桌面。常驻桌面的窗口成为桌面卡片，重启后自动恢复；在桌面上点 × 只会移出桌面，不会停止插件。
- 常驻桌面的卡片失焦时，状态栏收成一条细条，悬停或聚焦时展开；更多菜单可锁定位置；第一次放到桌面时会提示呼出插件栏的快捷键。
- 拖动或缩放桌面卡片时，会吸附到屏幕和其他卡片的边缘；再次打开已在桌面上的窗口时，会浮起并高亮这张卡片。
- 设置页移除「编辑桌面」全局模式，所有卡片都可以直接在桌面上拖动。

### 插件栏

- 新增「添加插件」：可搜索并打开插件窗口，已打开的窗口会直接复用；点星标可把常用窗口放到插件栏上作为快捷按钮。

### 搜索

- 文件名和正文搜索改用 Everything 1.5。

### 启动器与稳定性

- 修复启动器回车、便签删除、设置回滚和退出流程中的若干问题，并加强官方插件身份和宿主边界检查。
- 翻译历史在 Windows 临时重命名失败时会自动重试。

### 插件开发（宿主 API 1.7）

- 网页插件窗口的标题栏统一由宿主绘制，`titleBar` 声明已废弃，自绘标题栏的插件需要删除自绘部分。
- 新增 `client.window.setStatus({ subtitle, runState })` 和窗口声明 `desktopMinSize`。
- 插件清单可以声明启动器配额、即时查询、常驻列出和命令超时。

### 官方插件

- 应用搜索 1.1.6、快捷链接 0.1.1、流量监控 0.2.5、翻译 0.1.9；快捷链接和流量监控改用宿主状态栏。

### 验证

- 线上 CI 通过：typecheck、lint、格式检查、单元测试、浏览器 UI 测试，以及 Windows 安装包完整构建（含原生组件）。
