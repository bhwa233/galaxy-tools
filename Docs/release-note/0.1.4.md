## v0.1.4

### 快捷键与窗口

- 重新打开已显示但被遮挡的设置或插件窗口时，会重新聚焦并置前。
- 保存设置时只校验本次修改的快捷键；未修改但被系统占用的绑定（如默认 `Win+V`）只显示提示，不再阻止保存。

### uTools 兼容

- 每个 uTools 插件在应用就绪前使用独立的浏览器存储目录，不再共享 localStorage、IndexedDB 和 Cookie。
- 运行器启动失败后，下次激活可以重新启动。
- 动态功能写入时按宿主规则校验，读取时跳过无效条目，避免单个条目让整个插件失效。
- 激活与选择按顺序执行；选择结果时重置残留列表；上次隐藏回调超时不再导致下一次激活失败。
- `postAttachment` 遇到已存在的文档返回冲突，不再覆盖。
- 桌面固定插件逐个恢复，单个插件失败不影响其余插件。
- 来源绑定的安装预览可以取消，且不会删除已安装插件。

### 验证

- typecheck、lint、格式检查通过；Node 测试 358 项通过。
