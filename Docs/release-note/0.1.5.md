## v0.1.5

### 更新

- 检查完更新后，如果已是最新版本，便签窗口不再显示更新图标。
- 设置的「常规」页提供检查更新、下载和安装入口；便签窗口的「关于」面板只显示更新状态，并提供「前往设置更新」按钮。

### 托盘菜单

- 新增「桌面卡片显示」子菜单，可逐个切换桌面卡片（如桌面流量窗）的显示和隐藏，并与设置页、卡片右键菜单的状态同步。
- 每个插件在托盘菜单中只占一个顶级项，插件功能都在其子菜单中；「找回便签」移入便签的子菜单。

### 插件

- 流量监控插件新增图标，版本升至 0.2.4。
- 已安装插件与当前宿主版本不兼容时，如果内置包中有更新的兼容版本，启动时会自动替换，并保留插件数据。
- 移除示例插件 hello-web。

### 退出

- 退出因保存未确认而取消时，提示框会写明未确认的窗口或插件及原因。

### 验证

- typecheck、lint、格式检查通过；Node 测试 359 项通过。
