# 桌面时钟示例

这个预构建插件包包含两个桌面卡片模板：

- **简洁时钟**：宿主声明式卡片，展示当前时间，默认鼠标穿透。
- **交互时钟**：隔离 Web 卡片，接收同一个 `host.clock` 的时间戳；“显示日期”按钮通过受限 SDK 调整当前卡片大小。

两者均不需要后台、Node、原生执行、文件、网络或剪贴板权限。模板可以分别创建多个实例，每个实例的布局由宿主管理。Web 页面只接收宿主推送，不自行轮询系统或访问网络。

## 打包与导入

需要包含桌面卡片合同的宿主 API **1.4.0**；`api` 范围明确为 `>=1.4.0 <2.0.0`。这是运行合同版本，不是 SDK npm 包版本。

在仓库根目录选择项目 Node/pnpm 后执行：

```powershell
pnpm --dir examples/plugins/desktop-widgets pack --out ../../../local-build/desktop-layer/example-desktop-widgets.tgz
```

随后从宿主插件管理页导入该本地 `.tgz`，启用插件，在桌面卡片管理中添加“简洁时钟”或“交互时钟”。安装不会自动铺出所有模板；宿主桌面层未启用时会保留实例并显示挂起原因。Web 卡片还要求宿主允许隔离 Web 展示。

示例没有安装/构建脚本，也没有运行时 npm 依赖；包内 HTML、CSS、JS、JSON 已可直接读取。`/__sdk__/widget.js` 是宿主提供的固定浏览器 SDK，不需要打包整个 SDK 或解析 `node_modules`。

## 使用行为

卡片位置、置顶和恢复偏好跟随各自实例保存；停用插件释放视图，保留布局。临时关闭日期只改变当前 Web 视图，重载后恢复默认，不声称拥有插件业务配置持久化。需要持久业务配置的插件应使用自己的 dataDir 和版本迁移。

简洁时钟的移动和移除由宿主编辑模式提供，页面本身没有点击入口；交互时钟的按钮只调整本卡尺寸，不打开主窗或调用其他插件命令。其拖动从宿主手柄开始，不能依靠 iframe 内部事件冒泡。

资源和输入模式的实际开销、物理点透、多屏与 DPI 表现以宿主验收为准；示例本身不修改 feature flag 或授权。
