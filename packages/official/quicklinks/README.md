# 快捷搜索与参数化快开

独立的 `spark233.quicklinks` 插件，支持通过启动器输入关键词搜索网站、打开应用链接或向 EXE 传入动态参数。搜索和配置预览不会打开外部目标；回车执行后才交给默认浏览器或已配置的程序。

在启动器搜索“快捷搜索”可进入管理页；托盘菜单和插件管理也提供打开入口。默认包含百度 `bd`、必应 `bing`、Google `gg`、哔哩哔哩 `bili`、GitHub `gh`、知乎 `zh`。例如输入 `bd 深圳天气`，回车使用默认浏览器搜索。也可直接输入网站名称找到入口，回车后填写内容。

管理页支持新增、编辑、启停、删除，以及添加预设。点击“保存配置”后立即用于后续搜索；切换条目不重新读取配置。尚未保存的修改会阻止窗口关闭或插件停用，可先保存或放弃修改。保存使用配置版本检查，拒绝覆盖其他窗口或外部更新。

## 模板

- `{query}` 接收关键词后的全部内容。
- `{owner}`、`{repo}`、`{笔记库}` 等命名字段会在执行前显示填写框。
- 网址字段自动使用 URL 编码。例如 `https://github.com/{owner}/{repo}`。
- URL 协议和域名固定，参数只能用于路径、查询或片段。支持 HTTP、HTTPS、VS Code、Obsidian、Notion、Zotero、mailto。
- EXE 路径和工作目录固定；每行一个启动参数，支持同样的占位符。带空格的一个参数仍占一行，无需自行加引号。
- 固定网址或无需参数的程序也可使用。静态应用／文档／目录收藏仍可通过原有应用搜索管理。

程序执行复用宿主的 EXE 验证与独立 argv 启动流程，不经过命令解释器。搜索结果保留条目版本，配置变更后旧结果不能执行。普通搜索仅启动独立后台；管理或填写参数时才创建沙箱窗口，并使用共享主题及自定义标题栏。

## 数据与构建

配置存储在插件自己的 `dataDir/quicklinks.json`，最多 200 个入口，配置总大小上限为 192 KiB。坏配置原样保留并报告错误。停用释放窗口、后台和监听，保留配置数据。

使用仓库选择的 Node 26 / pnpm 12 工具链，运行 `pnpm --filter @spark233/plugin-quicklinks build`。单插件产物默认位于 `local-build/spark233/plugin-artifacts/spark233.quicklinks/`；全量 `pnpm build` 会将其加入官方离线目录。单独更新插件时应递增 package version。
