# 流量监控、桌面提示与程序历史

实时列表的「⋯」和行右键提供定位文件、Windows 原生文件属性、查看连接与结束进程。展开后的子行仅作用于该 PID，父行结束操作明确列出全部选中的进程，并要求确认。菜单和确认窗口保留打开时的实例标识，刷新不会将目标替换成新进程。原生客户端先复用现有连接接口的用户范围授权，再以同一进程句柄校验创建时间、所有者和路径后执行；结束操作遵循普通客户端权限，不经 SYSTEM 服务提权，拒绝本应用及采集服务/系统关键进程。

桌面流量窗宽度固定为 110 DIP，高度按两行内容和上下等量留白自适应，收紧内部间隔以容纳较长的速率数值与单位，数字变化不调整窗口宽度。实际窗口和输入区域使用相同尺寸，保留字号、拖动与贴边位置。限速不在本插件此次变更范围内。

首版采集 **活动物理网卡的接口总量**，包含局域网流量。它使用 Windows 自带的 PowerShell 与 .NET/IP Helper 累计字节计数，后台保持一个串行采集器，以 1 Hz 计算速率。不是按进程 ETW 统计，不推测代理/VPN 逻辑流量，也不将网卡总量冒充互联网流量。

启用插件后后台独立采样。打开“流量监控”查看实时速率、网卡索引与地址，并可明确暂停或恢复采集；在宿主“设置 → 桌面”添加“网卡流量 HUD”。关闭主页面、隐藏或移除 HUD 只释放显示订阅；显式暂停停止采样，停用插件释放 utility backend 和 PowerShell 采集器。停用保留暂停偏好与宿主管理的卡片布局。

安装检查不会启动采样器。插件声明 `node.backend` 和 `native.process`，按现有信任确认授权，并将平台限定为 Windows。主页面使用现有独立 Web 窗口合同，不申请宿主内部 `windows` 能力。采集器只执行包内固定脚本；页面不能提交路径、PID、shell 命令或任意采样参数。主页面通过当前 owner 的受限 `node.backend/invoke` 操作调用本插件公开无窗命令；HUD 使用同一后台的声明式订阅。

每个接口以 GUID 稳定标识，并带上实时 IP 与接口索引。每 30 秒更新一次物理网卡发现，累计计数每秒读取；NIC 热插拔、索引/IP变化、计数重置、超过 5 秒的采样空白、暂停恢复和进程重启均重新建立基线。warming/gap/paused/unavailable 时速率为 null、HUD 显示“—”，趋势清空，不补零、不推算缺失数据。

默认不加总虚拟、隧道和 loopback 接口，避免 Hyper-V/VPN 多层重复计数。物理网卡收发仍可能包含 VPN 封装后的字节，且并不等于应用有效载荷。首次发现 NIC 可能较慢；不可用时保留错误状态并提供“重新连接”。Windows 电源/驱动如何维护计数以实际返回值为准，采集不尝试提权。

0.2.0 增加独立的 .NET Framework 4.8 Windows 服务、普通用户 native-v1 bridge，以及固定 UAC 安装/授权 helper。窗口继续使用上述接口总速；程序排行、TCP/UDP 详情和历史使用服务实际采集的 ETW 数据，两种口径不强行对齐。不提供限制网速或程序限速。当前原生闭包为 Windows x64。

桌面提示为固定 110 DIP 宽、高度随内容自适应的两行卡片，上传橙色、下载绿色。悬停显示宽度 260 DIP 的两个 Top 3 排行，移入排行继续保留；左键打开或复用详情窗口，拖动不触发打开。右键提供“窗口置顶显示”（默认开）、“贴边自动隐藏”（默认关）、“全屏时自动隐藏”（默认开）、“查看流量详情”和“关闭流量提示”。关闭提示只隐藏展示，保留布局、采集意图与历史。三个偏好按实例保存；贴边收起使用约 180 ms 位移动画并保留 4 DIP 唤回条，只改变临时几何。普通 HUD 与排行共用稳定的局部工具窗，避免透明整屏原生窗口影响底层浏览器遮挡判定。

详情窗口包括实时/历史页签、程序分组和实例展开、搜索/筛选/排序、连接弹层、日期预设/自定义范围以及历史清空确认。页签切换保留状态；鼠标或键盘正在操作表格时保留行顺序，数值继续更新。大量记录及图标沿已有受限插件能力通道分页，图标分片不放宽单消息/单字符串安全上限。

实时页的“本次下载／本次上传”由 ETW 服务按进程实例与应用连续运行会话累计实际字节。同路径、同用户的多个进程合并为一个运行会话，退出成员的字节保留；全部成员退出后再次启动开启新会话。关闭详情、切换页签、bridge 重连及清空历史不会清零。独立运行 checkpoint 与历史共用 SQLite 文件但不受历史清理／保留期影响；异常重启只恢复已落盘计数并标记缺口，不估算离线流量。应用先于监控启动时，只统计实际观测部分。所有视图统一使用 KB／MB／GB 与 KB/s／MB/s／GB/s 标签，保留 1024 进位及原始字节精度。

历史列表返回固定大小的覆盖摘要，不再将完整覆盖区间重复塞进每一页；历史行继续按消息预算和不透明游标分页。摘要扫描全部相关区间，不截断前 1000 条；行、摘要和 durable 时间来自同一数据库读事务。已有历史数据库和记录原样保留。

首次点击“启用进程采集”才会启动固定安装 helper，Windows UAC 由用户处理。当前账户范围为默认；“整机”需要单独授权，切换查询范围本身不触发 UAC。服务按实际 pipe token 校验 SID；bridge 在发送请求前验证服务端身份。代码部署到 ProgramData 下受保护的版本目录，历史目录不授予普通用户直接读取权限。状态查询不会自行启用采集。

服务按 boot、PID 与创建时间识别进程，字节通过十进制字符串传输。分钟桶保留 48 小时、小时桶 90 天、日桶 2 年；低排名进程照常保存。历史粒度随保留期选择，粗粒度范围对齐 UTC 桶并在页面显示实际边界。没有覆盖的时段显示缺口或不可用，不把缺失记录补成零。UDP 本地端点与实际观察到的远端流分别展示，远端不写入历史。

显式暂停保存恢复范围，撤销当前用户的采集意图；继续和重启后继续可恢复这些范围。停用/退出先等待最终落盘，再释放 bridge 租约及进程。服务没有有效租约时停止 ETW；不停止其他软件的 ETW 会话。安装检查不启动采集，后台普通启动只恢复之前明确启用的范围。

构建：在仓库选择项目 Node/pnpm 后执行 `node scripts/build-official-plugins.mjs --plugin spark233.traffic`。生成安装包位于 `local-build/spark233/plugin-artifacts/spark233.traffic/`。缺少或源码已变更的原生闭包通过 `scripts/native-traffic/build.ps1 -StageDirectory packages/official/traffic/native` 进行锁依赖构建与哈希 staging；执行它不会安装服务。完整官方构建也会包含此插件；桌面实例仍由宿主设置管理。正式升级需要重新走可见的受保护服务安装路径，不静默覆盖正在运行的 SYSTEM 代码。

验证边界：普通权限隔离测试可验证 bridge/管道/历史/租约和无服务空态；真实 ETW TCP/UDP 归属、UAC 安装/升级/回滚及签名发布需要相应权限与真机出口。编译成功不能代替这些验收。
